    Each criterion is scored 0–5, then multiplied by its weight ÷ 5, for a total out of 100. Each job has one best pick and one free alternative.

    Evidence rules

  • Every fact has a link and the date we checked it (all of v2 was checked on 14 Oct 2026).
  • We use the vendor's own page first. Anything else is labelled secondary and queued for a re-check.
  • No invented benchmarks, prices or features. If we can't find it, we write unknown.
  • Leaderboards rank models, not apps. We name the model and say which app gives you access to it.
  • Labels: Tested, Sourced only or Unknown. v2 is all Sourced only, because we test free tiers only and haven't run tests yet.
  • Weekly price checks and a monthly re-rank, with a public change log. Anything not re-checked in 60 days is flagged stale.
  • No paid placements. Any affiliate link is disclosed and never changes a ranking.
